# Responsive Product Pricing Cards

## About
A modern SaaS pricing webpage developed
using HTML, CSS and JavaScript.

## Features
- Three pricing plans
- Monthly and yearly billing toggle
- Popular plan highlight
- Smooth hover effects
- Responsive mobile layout
- Accessible billing buttons

## Technologies Used
- HTML5
- CSS3
- JavaScript
- CSS Grid
- CSS Transitions

## How to Run
Open index.html in your browser.
